A responsive, clean, and professional personal portfolio website built to showcase my skills, projects, and educational background as an engineering student at Ajay Kumar Garg Engineering College.

## 🚀 Live Demo
[View the Live Site on Vercel]( https://teamconatus-m8a6.vercel.app/)

## 🛠️ Built With
* **HTML5:** Semantic structure and content.
* **CSS3:** Custom styling, Flexbox, CSS Grid, and responsive design (no external frameworks).

## 📂 Project Structure
This project is located in the `Portfolio` directory of the `teamconatus` repository.

## 💻 Local Development
To run this project locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/krishnaa021/teamconatus.git
   ```
2. Navigate to the portfolio folder:
   ```bash
   cd teamconatus/Portfolio
   ```
3. Open `index.html` in any modern web browser.

## 🚀 Deployment
This site is deployed using [Vercel](https://vercel.com). 
* The deployment is configured with the **Root Directory** set to `Portfolio`.
* Pushing updates to the `main` branch of this repository will automatically trigger a new build and deployment on Vercel.
